# Workflow Naming Convention

Workflow names in this repository should be plain technical names that describe the pipeline activity.

## Canonical Workflow Names

- `Constraint Generation`
- `Test Generation`
- `Implementation Testing`
- `Bug Report Generation`

## Rules

- Do not prefix workflow or agent display names with `NRF`.
- Do not suffix workflow display names with `Workflow` or `Stage`.
- Use gerund/process nouns for workflow names.
- Reserve `Agent` for LLM-backed components.
- Use `Tester` for deterministic implementation execution.
- LLM agent display names should be short labels:
  - `Constraint Agent`
  - `Test Agent`
  - `Bug Report Agent`
- `json/AllOpsMetaData.json` is static metadata input. It is not generated by a workflow.
- `Bug Report Generation` uses bug-report packaging, but generated prose should stay evidence-based and cautious.
